# Genesis - Universal Project Architect

**Status:** Vision & Planning Phase  
**Created:** January 5, 2026  
**Creator:** Dylaroo

---

## What Is This?

A universal project architect system that deeply understands ANY project, designs custom workflows, and builds domain-specific agent teams—not just for software, but for manufacturing, therapy, music production, healthcare, and anything else.

## Core Philosophy

**Understanding FIRST, Solutions SECOND.**

Most AI systems jump to solutions. Genesis invests in comprehension. You should say: *"You understand my project better than I could explain it."*

## How It Works

| Phase | What Happens | User Involvement |
|-------|--------------|------------------|
| **Phase 1** | Deep Project Understanding | High - validation loops |
| **Phase 2** | Workflow Planning | Medium - reviews plans |
| **Phase 3** | Team Building | Low - approves final team |
| **Phase 4** | Execution Orchestration | As needed - checkpoints |

## Key Differentiators

- **Universal Domain Support** - Not just code. Manufacturing, therapy, music, healthcare, anything.
- **Gap Discovery** - Finds what you didn't know you were missing
- **Research-Backed Agents** - Creates specialists that mimic real-world experts
- **Workflow-First** - Plans execution BEFORE building teams
- **Smart Reuse** - Adopts existing BMAD/EMAD agents when applicable
- **Portable Memory** - Memvid stores project context as portable video files

## Tech Stack

- **AgentScope** - Multi-agent orchestration with fault tolerance
- **Memvid** - Video-based portable memory
- **BMAD v6** - Base framework and agent patterns
- **BoMB** - BMad Builder for agent creation
- **EMAD** - Pre-built agents when applicable
