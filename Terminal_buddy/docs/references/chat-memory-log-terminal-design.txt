### 4. The "Terminal Engine" Decision (Most Important)
**Do not fork WezTerm unless you absolutely have to.**
*   **The Risk:** Forking a complex GPU terminal emulator means every time WezTerm updates (security fixes, new features), you have to manually merge those changes into your fork. This is a "maintenance trap."
*   **The Better Way:** Tauri allows you to build a native window. Inside that window, you can embed the **`wezterm-term`** crate (the core logic library) directly.
    *   **Benefit:** You get the same GPU rendering and speed.
    *   **Benefit:** You control the UI shell (Buddy Panel) completely.
    *   **Benefit:** You can update the terminal engine just by changing a version number in `Cargo.toml`.
*   **Action:** Investigate embedding `wezterm-term` or `alacritty_terminal` into a Tauri window before committing to a full fork.
